# Brush & Eraser Quick Start Guide

## 🎨 New Features Available!

### Brush Tool
- **Shortcut:** Press `B`
- **Button:** Click "Brush" in Insert menu
- **Features:**
  - Adjustable size (1-100px)
  - Color picker
  - Real-time preview

### Eraser Tool
- **Shortcut:** Press `E`
- **Button:** Click "Eraser" in Insert menu (next to Brush)
- **Features:**
  - Adjustable size (1-100px)
  - White brush for erasing
  - Shares size slider with brush

---

## How to Use

### Drawing with Brush
1. Press `B` or click "Brush" button
2. Settings panel appears at bottom center
3. Adjust size with slider or +/- buttons
4. Choose color from color picker
5. Draw on canvas!
6. Press `Esc` to exit brush mode

### Erasing Content
1. Press `E` or click "Eraser" button
2. Settings panel appears (no color picker)
3. Adjust eraser size
4. Erase by drawing white over content
5. Press `Esc` to exit eraser mode

---

## Settings Panel

When brush or eraser is active, you'll see:

```
╔════════════════════════════╗
║  Brush Size      [−] 4px [+]  ║
║  ━━━━━━●━━━━━━━━━━━━━━━  ║
║                            ║
║  Color    [■] #000000      ║  ← Only for Brush
║                            ║
║  Press Esc to exit         ║
╚════════════════════════════╝
```

**Controls:**
- **Slider:** Drag for precise size (1-100px)
- **Minus (−):** Decrease by 2px
- **Plus (+):** Increase by 2px
- **Color Box:** Click to pick any color
- **Hex Code:** Shows current color

---

## Tips & Tricks

### Size Control
- **Small details:** 1-5px
- **General drawing:** 4-10px  
- **Thick strokes:** 20-50px
- **Large fills:** 50-100px

### Working with Layers
- Brush/eraser strokes create Path objects
- They appear in Layers panel
- Can be selected, moved, scaled, rotated
- Can be deleted individually

### Keyboard Workflow
1. `B` - Start drawing
2. Draw your content
3. `E` - Switch to eraser
4. Fix mistakes
5. `B` - Back to brush
6. `Esc` - Done!

## Examples

### Drawing a Signature
1. Press `B`
2. Set size to 2-4px
3. Choose black or blue color
4. Draw your signature
5. Press `Esc` when done

### Creating Highlights
1. Press `B`
2. Set size to 20-30px
3. Choose yellow (#ffff00)
4. Draw over text/areas
5. Press `Esc`

### Fixing Mistakes
1. While drawing, press `E`
2. Erase unwanted parts
3. Press `B` to continue drawing
4. Or press `Esc` to finish

## Troubleshooting

**Settings panel not showing?**
- Make sure brush or eraser is active
- Press `B` or `E` to activate

**Color picker not visible?**
- Color picker only shows for Brush
- Eraser always draws white

**Can't exit brush mode?**
- Press `Esc` key
- Or click another tool

**Strokes not appearing?**
- Check brush size isn't too small (< 1px)
- Check color isn't same as background
- Try increasing size to 10px
